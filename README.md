# Case-Study-1
# 🛒 E-commerce Product Sorting Using Divide and Conquer

> A simple Python-based E-commerce Product Sorting System developed using the **Merge Sort Algorithm** and the **Divide and Conquer Technique**.

---

## 🎯 Objective

To develop a simple and user-friendly E-commerce Product Sorting System using Python that sorts products according to their prices in ascending and descending order using the Merge Sort algorithm.

---

## 📖 Introduction

The **E-commerce Product Sorting System** is a simple application that demonstrates how products can be arranged according to their prices in an online shopping platform.

The project uses the **Merge Sort algorithm**, which follows the Divide and Conquer technique. In this technique, the list of products is divided into smaller parts, sorted individually, and then merged to produce the final sorted list.

The application allows users to view available products and sort them from lowest to highest price or highest to lowest price.

This project demonstrates the practical application of sorting algorithms in real-world e-commerce applications.

## 🧩 Algorithm Used

### Merge Sort

Merge Sort is a sorting algorithm based on the **Divide and Conquer** technique.

The algorithm works in three main steps:

- **Divide:** Split the list of products into smaller sublists.
- **Conquer:** Sort each sublist recursively.
- **Merge:** Combine the sorted sublists to produce the final sorted list.

**Example:**

Unsorted prices:

`[500, 200, 800, 100, 400]`

Sorted in ascending order:

`[100, 200, 400, 500, 800]`

Sorted in descending order:

`[800, 500, 400, 200, 100]`

### Time Complexity

- Best Case: O(n log n)
- Average Case: O(n log n)
- Worst Case: O(n log n)

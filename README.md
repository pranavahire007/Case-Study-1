# Case-Study-1
## Description

The E-commerce Product Sorting System is a Python-based application designed to sort products according to their prices using the Merge Sort algorithm. In an e-commerce platform, users often need to arrange products from lowest to highest price or highest to lowest price to find suitable products easily.

This project uses the Divide and Conquer technique, in which the list of products is divided into smaller parts, each part is sorted separately, and the sorted parts are merged to produce the final sorted list. The application allows users to view the available products, sort products in ascending or descending order, and display the sorted results.

The main objective of this project is to understand the practical application of sorting algorithms and analyze their efficiency. Merge Sort has a time complexity of O(n log n), making it an efficient algorithm for sorting large lists of products.

This project demonstrates how fundamental Data Structures and Algorithms concepts can be applied to real-world e-commerce applications.
